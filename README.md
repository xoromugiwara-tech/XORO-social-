# XORO-social-

A simple real-time social messaging web app built with React, Firebase, and Vite.

## Features

- 🔐 Email/password authentication
- 🔵 Google authentication
- 👤 User profiles
- 📸 Profile pictures
- 💬 Real-time chat
- 🔑 Create unique chat codes
- 🤝 Join chats using a code
- ✍️ Real-time typing indicator
- 🔔 Unread message indicators
- 🔎 Chat search
- 📋 Copy chat codes
- 📱 Mobile-friendly interface
- ⚡ Firebase Firestore real-time database

## Tech Stack

- React
- Vite
- Firebase Authentication
- Firebase Firestore
- Lucide React
